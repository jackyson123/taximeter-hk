# 香港的士神算錶 · TaxiMeter HK

香港的士車資即時估算器 —— 輸入起點同終點，即刻算出真實行車路程、自動偵測過海隧道、跳錶車資、附加費同 AA 拆數。零依賴單頁網頁，離線可用（除路線同地點搜尋）。

## 功能

**路線**
- 起點 / 終點兩個輸入，附 `⇅` 交換掣，支援即時自動完成：內置 75 個香港熱門地標、港鐵站、機場、口岸、商場、醫院，同時即時搜尋 OpenStreetMap 全香港任何地址（英文或中文都搵到）。
- 真實行車路線由 OSRM 計算，回傳實際駕駛距離（公里）同預計行車時間（分鐘）。
- 自動偵測過海：用香港島海岸線多邊形判斷起點終點係唔係喺海港兩岸，再用路線幾何揀出實際用嘅隧道（紅隧 / 東隧 / 西隧），自動加隧道費，唔會漏。
- 迷你路線摘要：`約 9.6 km · 預計 12 分鐘 · 經紅隧過海`。
- 可以隨時手動拉距離微調（摺疊式「手動微調距離」），改完一按「還原」就回到真實路線距離。

**咪錶**
- 紅的（市區）／綠的（新界）／藍的（大嶼山）三款，各自落旗價、跳錶率、長途分段同顏色主題。
- 7 段 LED 數碼顯示，跳錶有動畫同 Web Audio 音效。
- 行李（$6/件）、動物雀鳥（$5/隻）、電話電召（$5）附加費。
- 85 折、自訂折扣（只計咪錶車費，隧道費同附加費照全費 —— 同香港實際做法一樣）。
- 過海隧道單程／來回切換。
- AA 拆數：最多 8 人，每人金額向上取整至 0.1 元，一按複製 PayMe / FPS 訊息。

## 收費基準

依運輸署《的士收費表》（2024 年 7 月 14 日生效，2026 年 5 月 7 日修訂版）：

| | 紅的（市區） | 綠的（新界） | 藍的（大嶼山） |
|---|---|---|---|
| 落旗（首 2 km） | $29.0 | $25.5 | $24.0 |
| 首段 | $2.1 / 200 m（2–9 km） | $1.9 / 200 m（2–8 km） | $1.9 / 200 m（2–20 km） |
| 長途 | $1.4 / 200 m（9 km+） | $1.4 / 200 m（8 km+） | $1.6 / 200 m（20 km+） |

三條過海隧道（紅隧、東隧、西隧）的士劃一 $25。咪錶唔包隧道費，唔喺過海的士站上車要另加 $25 回程費。

## 資料來源

- 地點搜尋：[Nominatim](https://nominatim.openstreetmap.org/)（OpenStreetMap），失敗時自動退回 [Photon](https://photon.komoot.io/)。
- 行車路線：[OSRM 公共路由伺服器](https://project-osrm.org/)，`route/v1/driving`，`overview=full` GeoJSON。
- 香港島海岸線：OpenStreetMap 邊界簡化而成，用嚟判斷過海。
- 地圖資料 © OpenStreetMap 貢獻者（ODbL）。

兩個服務都支援跨來源（CORS `*`），所以本app 係純靜態網頁，唔需要後端代理。

## 本機執行

```bash
python3 -m http.server 8080
# 開 http://127.0.0.1:8080
```

直接開 `index.html` 都得，但用 `http://` 開先會有 PWA manifest 同 clipboard 權限。

## 部署

純靜態檔（`index.html`、`manifest.json`、`icon-192.png`、`icon-512.png`），可以放任何靜態主機：GitHub Pages、Vercel、Netlify、Cloudflare Pages。

## 注意

神算錶只作估算參考，實際車資以的士咪錶及司機收取為準。85 折屬私下協議，非法定收費。路線同時間取決於第三方路由服務，繁忙時間實際行車時間會有出入。
